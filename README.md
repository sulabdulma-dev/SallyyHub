# SallyyHub — Portfolio Website

Portfolio website for Suleiman Abdimalik. This repository is a simple static site; keep the HTML, CSS, JavaScript, and image files in the repository root unless you also update every corresponding path.

## Files

- `index.html` — home page
- `about.html` — profile and biography
- `skills.html` — skills and certifications
- `work.html` — projects and field work
- `resume.html` — experience and education
- `contact.html` — contact details
- `style.css` — shared styles
- `main.js` — mobile navigation and footer year
- `profile.jpg`, `project1.jpg`, `project2.jpg`, `project3.jpg` — profile/project images
- `unicef-logo.jpg`, `unhcr-logo.jpg`, `icrc-logo.jpg`, `disasterready-logo.jpg` — certification logos

## Customize

Edit the relevant HTML page to update text. Edit `:root` in `style.css` to change the colors, fonts, and spacing. Replace the image files in the root with your own images, keeping the filenames the same, or update the matching `src` values in the HTML. Add a real `resume.pdf` before creating a download link for it; the current resume page lets visitors request a CV by email.

## Run locally

Open `index.html` in a browser. For local web-server testing, use any static server. The site can be deployed to GitHub Pages, Netlify, or Vercel.
